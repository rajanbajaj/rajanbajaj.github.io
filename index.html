03 Spotlight: OpenLens

Private AI search engine · Meta Global AI Developer Hackathon · Oct – Nov 2026

OpenLens is a self-hosted search engine over your own crawl, with an Agentic AI Mode on Muse Spark. A 10-stage pipeline — parse, rewrite, retrieval, normalize, dedupe, filter, score, rank, enrich, explain — sits behind stable plugin/provider interfaces (Python/FastAPI, Postgres custom index with plainto_tsquery + ts_rank, React/Vite, Docker Compose).

  • Agentic mode: dependency-free OpenAI-compatible client for query rewrite, budgeted index tools, and cited synthesis with extractive fallback — fail-closed to standard results with typed ProviderError envelopes.
  • Distributed crawl fleet: Postgres frontier (120s leases, heartbeats, priority dequeue) + Kafka consumer groups, robots/page-budget gates, 5s fetch bound, retry on 429/5xx only, ClickHouse analytics sink, Redis result cache.
  • Debugged in prod from pg_stat_activity and broker logs: leaked-idle-transaction wedge, missing-index dashboard, queue-cap eviction deadlock; consolidated 3 KRaft brokers to 1.
  • Release gates: tag-only serialized releases, ruff + mypy zero-error, offline pytest with fakes, vitest + tsc, pip/npm audit, gitleaks.
